# Evidências

Cada execução deve ter uma pasta identificada por data e ID único, contendo:
- `metadata.json` com versões, dispositivo e parâmetros;
- capturas web e Android originais;
- overlays e imagens de diferença;
- gravações de animação;
- logs de build, instalação, inicialização e automação;
- relatório final com testes aprovados, reprovados e inválidos.

Não substituir evidências anteriores. Execuções são imutáveis; correções geram nova execução.
